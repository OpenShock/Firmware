Editor-independent build setup for VS Code, CLion and plain CMake

## Release Note
The firmware now builds from any editor or terminal without the VS Code ESP-IDF extension and without sourcing an export script first, and the local workflow is documented in `docs/DEVELOPING.md`.

- `scripts/build.py` finds an ESP-IDF registered by the Espressif installer on its own, and `scripts/idfenv.sh` / `scripts/idfenv.bat` export the same environment for a shell or a CLion toolchain
- `CMakePresets.json` has a configure and a build preset per board, generated by `scripts/gen_cmake_presets.py`; `cmake --preset <board>` derives the chip and sdkconfig layers from `boards/<board>.defaults`, so CLion and a bare shell build and stamp a board like the script does
- Tracked `.vscode/` tasks call `scripts/build.py` for build, flash, monitor, menuconfig and the test suites, and `.clangd` follows the board or variant built last
- A build without a board fragment gets the 4 MB flash and OTA partition table every board uses, instead of overflowing ESP-IDF's stock 2 MB layout
